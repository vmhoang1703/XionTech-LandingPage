Brand typography

Four typefaces. One voice.

A type system drawn from the XionTechs logo: wide, confident capitals with a sense of forward motion. Every font here supports full Vietnamese diacritics.

Reading the logo

What the logo tells us about type

Extended capitals

"XIONTECH" is set in wide, geometric uppercase. Our display and label fonts echo that width so headlines feel related to the mark.

Mixed-case tagline

"Get IT Done" mixes cases with generous spacing. Brand labels use a wide face with open tracking to carry the same rhythm.

The swoosh

The amber arc is motion. Type stays clean and steady so the swoosh, the only curve, owns the energy.

For developers

Copy-paste tokens

<!-- in <head> -->
<link href="https://fonts.googleapis.com/css2?family=Unbounded:wght@500;600;700&family=Lexend+Exa:wght@400;500;600&family=Be+Vietnam+Pro:ital,wght@0,400;0,500;0,600;0,700;1,400&family=JetBrains+Mono:wght@400;500&subset=vietnamese&display=swap" rel="stylesheet">

:root {
  --font-display: "Unbounded", system-ui, sans-serif;
  --font-brand:   "Lexend Exa", system-ui, sans-serif;
  --font-body:    "Be Vietnam Pro", system-ui, sans-serif;
  --font-mono:    "JetBrains Mono", ui-monospace, monospace;

  --color-navy:   #163663;
  --color-amber:  #FFC000;
  --color-amber-tint: #FFCF06;
  --color-ink:    #0B1730;
  --color-mist:   #EEF2F9;
  --color-paper:  #FDFDFE;

  --text-display-xl: 700 4.5rem/1.05 var(--font-display);  /* -0.03em */
  --text-h1:         600 3rem/1.1 var(--font-display);     /* -0.025em */
  --text-h2:         600 2.125rem/1.15 var(--font-display);/* -0.02em */
  --text-h3:         700 1.375rem/1.3 var(--font-body);
  --text-body-l:     400 1.125rem/1.6 var(--font-body);
  --text-body:       400 1rem/1.6 var(--font-body);
  --text-label:      500 0.75rem/1.4 var(--font-brand);    /* uppercase, 0.16em */
  --text-data:       400 0.8125rem/1.5 var(--font-mono);
}
:lang(vi) h1, :lang(vi) h2 { line-height: 1.18; } /* room for stacked diacritics */
Rules

Do and avoid

Do

  • Use Unbounded only for headlines, never paragraphs.
  • Keep Lexend Exa uppercase and widely tracked.
  • Give Vietnamese headlines extra line-height (1.18).
  • Use amber as a highlight behind or under words, with navy text.
  • Load the vietnamese subset for every font.

Avoid

  • Michroma, Orbitron and Sora: they look futuristic but have no Vietnamese support.
  • Setting the brand name in a different font than the logo; use the logo file.
  • Uppercase Unbounded for long headings; the wide caps get hard to read.
  • Tight tracking on Vietnamese uppercase, where accents collide.
  • More than two fonts in one component.
